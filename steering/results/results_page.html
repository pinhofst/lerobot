Grasp attempts over time

Every gripper close in every run, from the provisional machine labels. Single-pen runs: 9 red pen, 3 green pen.

  • On a pen the measured gripper stalls at 6.3–10.4 while the policy commands about 0.
  • An empty close goes to 0.1–0.6.
  • The policy does reopen and retry, about every 3–5 s.
  • Grasps start with the tip computed at −0.5 to −1.1 cm (base_link z). Empty closes happen at −0.2 to −0.6 cm, the same depth.
  • So the misses are not obviously "too high". In the wrist view the pen sits between the jaw tips, so it is probably beyond or below the fingertips. A wrist camera cannot show that depth.

Offline colour effect

Does the colour word change where MolmoAct2 heads, observation held fixed? 8 two-pen scenes, 5 prompts × the same 64 seeds, frames at +0, +1, +2, +3 s after the first policy observation.

Pre-registered verdict unclear

Pre-registered rule: "unclear". It needs the run-resampled CI to exclude 0 and both layouts to be positive.

The bootstrap CIs resample only 8 runs (4 per layout), so they are approximate and too narrow. The t-interval over per-run means is shown beside them.

Per run

Colour effect = shoulder_pan of the “pick up the red pen” seeds minus the “pick up the green pen” seeds, movers only, signed so + is towards the red pen. Error bars are seed-resampled 95% CIs for one frame; most are narrower than the marker.

It is not robust across scenes. In the two earliest scenes (no_color_1/2) the words do not select the pen. In no_color_2, "red" heads to the green pen and every other prompt heads to red. Those scenes had the arm 3–6° more elbow-extended and the pens closer and larger, with the green pen's body running between the jaws. This is a post-hoc observation, not a tested cause. Run names here follow ANALYSIS_2026-10-02.md. SUMMARY.md drops “2_pens_”, so its red_1 is red_2_pens_1 here.

Aggregates and neutral drift

In plain language: the colour word steers the target in 6 of 8 scenes, in both layouts, by 3–18° of pan, so it is not position alone. "Position/learned direction dominates" is not supported: the neutral drift is about 2–3°.

Limits and next experiments

Limits

  • All outcome, contact and hover labels are provisional machine labels. The protocol's blind human labels have not been made.
  • Two-pen colour following rests on n = 3 named-colour runs. Gaps: “pick up the red pen” with red pen left, green pen right: 1 run(s); “pick up the red pen” with green pen left, red pen right: 0 run(s); “pick up the green pen” with red pen left, green pen right: 1 run(s); “pick up the green pen” with green pen left, red pen right: 1 run(s).
  • Not testable from these data. There is a single 4° run (16:11). It was also the only one with 2 fps frames, and it came before the 6° runs.
  • Episode length: 7 runs were stopped before 30 s (8.5–20 s), so episode length is not uniform. Note this when computing null rates.
  • Offline test: One wrist view.
  • Offline test: A 1 s chunk, read through pan only (no 3-D projection onto the pens).
  • Offline test: 8 scenes; frames within a run are correlated, so runs are the unit.
  • Offline test: JPEG (q85) frames, with the state taken from the next tick (≤33 ms).
  • Offline test: No RTC guidance offline, which matters for later chunks.
  • Offline test: The "" prompt is the out-of-distribution template.
  • Offline test: Pen position is the cap centroid.

Preliminary, from the analysis

  • Any colour-following claim. It rests on n = 3, with "red prompt, red on the right" never run and "green prompt, green on the left" run only once.
  • The offline prompt comparison points the same way. It found +6.0° of pan towards the named pen (CI −1.9 to +11.9), in 6 of 8 scenes, and only a 2–3° neutral rightward drift. Its pre-registered verdict is still "unclear" (SUMMARY.md).

Next, in priority order

  1. Counterbalanced two-pen block (fixed start pose):
    • Both layouts × red / green / neutral prompts, at least 3 runs each, in random order.
    • Must include red-on-the-right with the red prompt (never run) and more green-on-the-left.
    • The only test of colour-following vs position.
  2. Third-person camera and blind human labelling by the written rule. Needed for "first sustained contact", pushes, and the depth question behind the empty closes.
  3. RTC A/B on the same scenes:
    • --inference.rtc.execution_horizon 10 vs about 20, so that guidance covers the executed steps.
    • Measure seam jumps, hover time and clipping.
    • Record the merge data (rollout.py patch c).
  4. FK height check against table marks, then a grasp-depth check: does closing 1 cm lower or later turn empty closes into grasps?
  5. Within-session cap A/B (4° vs 6°, same scenes and start pose), display off.
  6. Frame-level follow-up of the scenes where parking came first (2_pens_1, 2_pens_5), using the offline prompt test on their first frames (SUMMARY.md flags no_color_1/2 as outliers).

Provisional machine labels
Status of the labels: every label here is a provisional machine label, not the protocol's human labelling: Contact comes from gripper stalls (label_provisional.py), plus a visual check of each contact sheet. The sheets are runs/<run>/plots/labels_provisional.png, and the labels are in results/labels_provisional.csv. The person labelling should overrule them.
Layout
Layout is from colour segmentation of the first policy frame, as left/right in the wrist view. The jaw centre is at x = 0.48 of the frame width.
Colour effect
Direction. From the recordings, the image shifts by −6.7 px per degree of pan (CI −9.4 to −4.3), so +pan turns the wrist view to the right. "Colour effect" = (red − green) pan among moving seeds, signed so that + means towards the red pen. CIs resample runs, then seeds. With only 4–8 runs these percentile CIs are approximate and too narrow (review, 3 Oct): a t-interval over per-run means gives about −3.6 to +15.6 for the headline and 6.8 to 13.5 for red-left. The verdict is unchanged.
Pre-registered verdict
Pre-registered rule: "unclear". It needs the run-resampled CI to exclude 0 and both layouts to be positive.
Hover/realign
At least 6 s with the gripper open and no grasp, in 9 runs. In 2_pens_2 and 2_pens_4 the pan and/or wrist_roll joints were commanded at their trained-range bounds for at least 2 s.
Retract/park
The policy commands lift −96° and elbow 84°, the clamp bounds of the trained range. It happens after misses (16:11 run, no_color_1), after a drop (no_color_2), or right at the start (2_pens_1, 2_pens_5). It looks like the policy's end-of-episode pose.
